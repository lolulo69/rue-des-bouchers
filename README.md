# Rue des Bouchers

Jeu 3D navigateur (three.js + Vite). Pilou Dubois, membre de l'Association de la rue des Bouchers (Vieux-Lille),
contre les terrasses de l'Estaminet La Ch'tite Bernadette (noms des commerces fictifs).

- Design : [GAME_DESIGN.md](GAME_DESIGN.md)
- Dev : `npm install && npm run dev`
